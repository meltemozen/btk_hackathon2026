# btk_hackathon2026

FinTwin-App
FinTwin-App, yapay zeka destekli kişisel finansal analiz ve mentorluk platformudur. Kullanıcıların finansal verilerini analiz ederek kişiselleştirilmiş öneriler sunar ve finansal bilinçlerini artırmayı hedefler.

## 🚀 Özellikler

- 🧠 **Akıllı Analiz**: Yapay zeka kullanarak finansal verilerinizi analiz eder.
- 📊 **Görsel Raporlar**: Anlaşılır grafikler ve özetlerle finansal durumunuzu gösterir.
- 📈 **Performans Takibi**: Kazanç ve harcamalarınızı kategorilere göre takip eder.
- 🔄 **Otomatik Kategorizasyon**: İşlemlerinizi akıllıca kategorize eder.
- 💬 **Sohbet Desteği**: Finansal konularda soru sorabilir ve tavsiye alabilirsiniz.

## 🛠️ Kurulum

### Ön Gereksinimler

- Python 3.9+
- Node.js 14+

### Kurulum Adımları

1. **Backend Kurulumu**
   ```bash
   cd FinTwin-App
   pip install -r requirements.txt
   uvicorn main:app --reload
   ```

2. **Frontend Kurulumu**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
